# DRILL13

`python main.py`로 실행합니다. Python 환경에 `pico2d`, `PySDL2`,
`transitions`와 SDL2 런타임이 필요합니다. 프로젝트 폴더에서 실행해주세요.

## 조작

| 키 | 동작 |
| --- | --- |
| Space | 타이틀에서 시작 / 플레이 중 선택한 공 발사 / 수면 중 깨우기 |
| ← / → | 캐릭터 이동 |
| E | 아이템 창 열기 / 닫기 |
| 0 | 아이템 창에서 공 장비 해제 (CLEAR) |
| 1 | 아이템 창에서 작은 공 선택 (21×21 픽셀) |
| 2 | 아이템 창에서 큰 공 선택 (41×41 픽셀) |
| P | 일시 정지 / 재개 |
| Esc | 플레이에서 타이틀로 복귀 |

아이템 창은 캐릭터 위를 따라다니며 화면 가장자리에서는 안쪽으로 보정됩니다.
선택한 카드는 초록색 테두리와 밑줄로 표시됩니다. 창이 열려 있어도 이동,
공 발사, 애니메이션, 수면 타이머가 계속 진행됩니다. E를 길게 눌러도
반복 입력으로 창이 깜빡이지 않습니다.

기본 장비는 작은 공입니다. 선택은 창을 닫아도 유지되며 새 게임에서는
초기화됩니다. CLEAR는 이후 발사를 막습니다. 이미 발사된 공은 기존
크기를 유지하고 화면 밖으로 나갈 때 제거됩니다. 숫자키는 아이템 창이
열렸을 때만 동작합니다. 수면 중에는 기존처럼 Space로 먼저 깨웁니다.

P는 아이템 창의 열림 상태를 보존한 채 게임을 멈추며, 다시 P를 누르면
재개됩니다. UI 글꼴은 Windows의 Consolas를 사용하며 Linux의 DejaVu
Sans Mono와 macOS의 Menlo도 지원합니다.

## 검증

`python -B -m unittest discover -s tests -v`

아이템 선택, 공 크기, 이동·발사 지속, 수면, P 일시 정지, 화면 가장자리,
타이틀 복귀와 세션 정리를 검증합니다.
